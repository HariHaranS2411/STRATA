Appendix: Known System Limitations & Honest Scope

  • Absence of calibrated barometric or RTK altitude produces flat 2D projection rather than true orthomosaics.
  • COLMAP and OpenMVS integrations require host GPU environments (NVIDIA CUDA) for high-throughput triangulation.

Roadmap to Full Validation Checklist

The exact engineering steps required to transition blocked and synthetic stages to 100% real data validated:

  • Install COLMAP
    Enables automatic SIFT feature extraction, spatial matching, and incremental SfM bundle adjustment.
  • Install OpenMVS
    Generates dense multi-view point clouds, Poisson mesh surface, and photometric texture blending.
  • Install FFmpeg with H.264/H.265 Hardware Acceleration
    Enables native keyframe extraction directly from 4K/60fps single-pass drone video files.
  • Add Camera Calibration Files (fx, fy, cx, cy, k1, k2)
    Resolves metric scale ambiguity and corrects radial lens distortion for millimeter-grade accuracy.
  • Add Ground-Truth 3D Data (LiDAR GCPs)
    Allows rigorous geometric root-mean-square error (RMSE) verification against ground control benchmarks.
  • Add Altitude & Barometric Telemetry Stream
    Unlocks true 3D spatial coordinate projection (Z elevation) missing from standard Aukerman and Shitan EXIF data.
  • Integrate AI Monocular Depth & Segmentation (Depth Anything V2 / SAM 2)
    Provides dense depth priors for sparse single-pass video frames where baseline parallax is narrow.

Install COLMAP & OpenMVS Toolchain

To enable real Structure-from-Motion and dense point cloud generation on your server or local machine, install the open-source photogrammetry binaries:

1. Install COLMAP (CUDA or CPU):
sudo apt-get update
sudo apt-get install colmap libcolmap-dev
2. Install OpenMVS for Dense Point Cloud & Meshing:
git clone https://github.com/cdcseacave/openMVS.git
cd openMVS && mkdir make && cd make
cmake .. -DCMAKE_BUILD_TYPE=Release
make -j$(nproc) && sudo make install
3. Run with Strata Daemon Bridge:
./strata-bridge --colmap=/usr/local/bin/colmap --openmvs=/usr/local/bin/OpenMVS

Once detected in your system PATH, the pipeline badges will automatically flip from ⛔ BLOCKED to ✅ WORKS (REAL DATA).
